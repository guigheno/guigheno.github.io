# Portfolio Daísy de Carvalho

Portfólio profissional da engenheira civil Daísy de Carvalho.

## Tecnologias

- [Astro](https://astro.build/) - Framework
- [Tailwind CSS](https://tailwindcss.com/) - Estilização

## Desenvolvimento

```bash
npm install
npm run dev
```

## Deploy

O deploy é feito automaticamente via GitHub Pages a cada push na branch `main`.
